# AI指挥台 · 视觉设计第二轮

第一轮的三个方向，用户和 Claude 的结论：

- **不分白天/夜间**。只有两套固定的样子：平时用的**普通模式**，和右上角开关打开的**炫酷模式**。
- **普通模式以方向 A（暖纸手作工坊）为底**
- **炫酷模式以方向 B（深海静谧舰桥）为底**
- 方向 C 太吵，不用；但它"每个助手身份鲜明"的思路值得借鉴，要克制地用

请做两个文件：

- `design/normal-v2.html`：普通模式
- `design/cool-v2.html`：炫酷模式

两个文件用**完全相同的布局骨架和示例数据**（还是第一轮 brief.md 里的数据，窗口 1280×820，一屏放下），因为在真正的程序里，炫酷模式只是同一个界面换了皮肤、换了画面内容，不是另一个页面。每个文件开头用注释写几句设计思路。

## 一、普通模式（基于 A）要改的地方

1. **框太多，像表格，看久了累。**
   - 每一行记录前面的"任务 / 动作 / 助手说"小标签框全部去掉。改用更轻的方式区分：比如行首一个很小的彩色符号或竖线、不同的文字颜色或字重。只有「助手说的话」和「提醒」值得稍微突出
   - 减少嵌套的边框：卡片里尽量不再套框，用留白、浅底色区分区域
2. **米黄纸底有点灰扑扑。** 保留温暖和不刺眼，但让它更清爽、更有精神：可以调底色的冷暖和明度，加一个有记忆点的强调色
3. **顶部信息区太挤**（步骤块、提醒块、说明块都各自带框）。压缩成更轻的两三行：需求一行，计划进度做成一条连贯的进度线（不是一堆框），提醒只在有事时出现
4. **"现在正在做什么"是每块画面的主角**，再大一点、更醒目
5. 左下角的"助手印记图例"去掉，占地方又没用

## 二、炫酷模式（基于 B）要改的地方

1. **英文标签全部换成中文**（CH-01、UNIT 01、NOW / WAIT / HALT / DONE、ALERT、BRIDGE 等）。数字、时间、token 可以继续用等宽字体
2. **画面内容不一样**：炫酷模式下，每块画面只留**一行大白话进展**（"现在正在做什么"），下面整块换成**滚动的代码流**，显示这个助手真实在跑的命令、输出和写进文件的代码。请用下面的示例代码流把它画出来，并让它有"正在滚动"的感觉（可以用 CSS 动画让内容缓慢上移，或者末尾一个闪烁光标）
3. 被阻碍、等你选择的画面，底部仍然要有选项按钮或回复框，要在深色里足够醒目
4. 保留 B 的氛围（层次、细线、光学感、克制的状态色），这是用户喜欢的地方

## 三、两个模式都要加的东西（让画面"有东西可看"，而且是真实数据）

1. **活跃度小波形**：每块画面一条细细的小图（像心电图或柱状），表示它最近 5 分钟每 15 秒做了几个动作。忙的时候起伏多，停下来就平。下面给了每个助手的示例数据（20 个数，从早到晚）
2. **"多久没动静"**：每块画面显示"最后动态：12 秒前"。运行中但超过 3 分钟没动静，要有一个温和的提醒样式（示例数据里 Codex·网页是 8 秒前，其他见下）
3. **新动态滑入**：最新的一行记录用一个轻微的出现动画（只演示一次即可）
4. **助手身份更鲜明但克制**：每家一个固定的标志和颜色（Codex、Antigravity、Claude），在画面标题、波形、记录符号上统一使用，让人不看文字也能认出是谁
5. **全局小结**：在某个不显眼但随时能看到的位置，显示"4 个助手 · 1 个运行中 · 2 个等你"这样的总览

# AI指挥台 · 视觉设计任务

## 这是什么

一个 Windows 桌面小程序（Electron），像监控室的监控墙：用户（一位不懂代码的个人创作者）把需求告诉 Claude，Claude 把活派给几个 AI 助手（Codex、Antigravity、Claude 助手）同时干，这个窗口实时显示每个助手正在做什么。用户会**长时间开着它、时不时看一眼**。

## 现在的问题（用户原话的意思）

现在的界面是"中性灰底 + 细线 + 只有状态才有颜色"的极简控制台风格。用户觉得**不好看、太枯燥，长期盯着会很无聊**。

## 要你做什么

做 **3 个风格完全不同的视觉方向**，每个方向是一个能直接用浏览器打开的单文件样板页：

- `design/direction-a.html`
- `design/direction-b.html`
- `design/direction-c.html`

每个文件开头用 HTML 注释写 3～5 句设计思路：这个方向叫什么、给人什么感觉、为什么适合长期盯着看。

三个方向要**真的不一样**（不是同一套换个颜色），比如可以分别往这些方向想（仅供参考，你可以提更好的）：
- 温暖、有手作感、像工作室的工作台
- 有深度和层次的夜间模式，像科幻电影里的舰桥，但克制
- 明亮活泼、有个性的、像一本好看的杂志或游戏界面

## 每个样板页必须包含（用下面的示例数据）

窗口尺寸按 **1280 × 820** 设计，所有内容一屏放下，不要整页滚动。

1. **左侧窄栏**：任务列表（2～3 个任务，当前选中一个）
2. **顶部信息区**（要紧凑）：任务标题、用户需求原话、Claude 拆出的 3 个计划步骤及各自进度、Claude 最新的一句说明、需要用户处理的提醒
3. **监控墙**：4 个助手画面排成 2×2，**每块大小固定**，块内的动态记录自己滚动。每块画面要有：
   - 助手身份（名字 + 是哪家：Codex / Antigravity / Claude），身份要一眼能认出来
   - 状态（运行中 / 等你选择 / 被阻碍 / 完成），运行中要让人感觉"它活着"
   - 用时、用了多少 token
   - **"它现在正在做什么"一行，要最醒目**
   - 动态记录列表：时间 + 一句大白话，分几类（助手说的话、它做的动作、你的回复、提醒）
   - 需要用户处理时，底部有选项按钮或回复框
4. 右上角一个「炫酷模式」开关（只画出开关即可）

## 必须避免（"AI 审美"）

- 紫色/蓝紫渐变、霓虹渐变背景、毛玻璃（glassmorphism）
- 满屏表情符号当图标
- 千篇一律的大圆角白卡片 + 阴影
- 为了好看牺牲信息：状态和"现在在做什么"必须一眼可读

## 可以大胆用

- 有个性的配色和排版（中文字体只能用 Windows 自带的：微软雅黑、等线、宋体、仿宋、楷体；英文和数字可用 Segoe UI、Cascadia Mono、Consolas、Georgia、Bahnschrift 等系统字体）
- 用 CSS 画的小图形、纹理、助手的"头像"或标志（不要用外部图片和外部字体，全部写在一个 HTML 文件里）
- 克制的动效：运行中的呼吸灯、活跃度小波形、新动态出现时的轻微过渡
- 让长时间看着不累的细节：合适的对比度、留白、节奏感

## 交付

三个 HTML 文件写进 `design/` 文件夹，最后用几句话说明三个方向的区别，以及你自己最推荐哪个、为什么。
